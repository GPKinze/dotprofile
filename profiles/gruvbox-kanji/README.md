# Gruvbox Kanji

An appearance preset for **Umbriel + Noctalia**, with a Gruvbox-inspired look and five Kanji workspace indicators: **【 一 二 三 四 五 】**.

## Appearance

- **Bar:** Customized built-in widget layout, capsule groups, and decorative brackets.
- **Workspaces:** Five named workspaces (`一`, `二`, `三`, `四`, `五`).
